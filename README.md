# 🎧 소리콩 교실 지킴이 — 시끄러운 교실을 지켜라!

> 6학년 과학 「소리의 성질」 심화 · 4차시 탐구 웹앱  
> 부산 명진초등학교 최일훈 · 2026

복도 소음이 교실로 몰려온다! 상자 미니 실험으로 재료별 소음 감쇠를 재고, 소리콩 AI와 자료로 원리를 알아본 뒤,
**소리콩 20개 예산**으로 가상 교실에 방음 장치를 설치해 교실 소음(약 67 dB)을 학교보건법 기준 **55 dB 아래**로 낮추는 탐구 앱입니다.

## 구조
| 위치 | 하는 일 |
|---|---|
| `index.html` | 화면 전체 (이 저장소, GitHub Pages) |
